1. 本ポリシーについて

本プライバシーポリシー（以下「本ポリシー」）は、Chrome拡張機能「EC商品『読み取りくん』」（以下「本拡張機能」）における、ユーザー情報の取り扱いについて定めるものです。

本ポリシーは、本拡張機能のバージョン 3.1.0 の動作にもとづいて記載しています。

本拡張機能をインストール・利用された時点で、本ポリシーに同意したものとみなします。

2. 取得する情報

本拡張機能は、ユーザーを個人として識別できる情報を一切収集しません。

本拡張機能の動作上、以下の情報をユーザーのブラウザ内で処理します:

  • ユーザーが「抽出開始」を押したページの内容（商品名・価格・JANコード・在庫状態・商品リンク・画像URL等）
  • 抽出対象タブのページURLおよびDOM情報
  • JANコードを補うために取得した商品詳細ページの内容（詳細は「5. 商品詳細ページの自動取得について」）

クリップボードへ出力する項目

上記のうち、ユーザーのクリップボードへコピーされるのは以下の3項目のみです:

  • JANコード
  • 仕入れ値（税込）
  • 商品リンク

商品名は、同じ商品を重複して出力しないための内部照合にのみ使用し、出力には含めません。在庫状態も出力しません。

重要
抽出した商品情報を、本拡張機能の提供者のサーバーや解析サービス等へ送信することはありません。本拡張機能が行う外部通信は「6. 外部への通信」に記載した2種類のみです。

3. 情報の利用目的

取得した情報は、以下の目的のためにのみ使用します:

  1. ECサイトの商品一覧ページから商品情報を抽出し、TSV形式に整形すること
  2. 商品一覧ページにJANコードが記載されていない商品について、同一サイト内の当該商品の詳細ページを読み取り、JANコードを補うこと
  3. 整形した商品情報をユーザー自身のクリップボードにコピーすること
  4. ポップアップを閉じて開き直したときに、直近の抽出結果をユーザーが再確認・再コピーできるようにすること
  5. 本拡張機能の利用可否（パスワードによる利用者確認）を判定すること

上記以外の目的で情報を使用することはありません。

4. 情報の保存場所と保存期間

本拡張機能は、抽出した商品情報を外部サーバーに保存しません。保存先はユーザーのブラウザ内に限定されます。

保存先保存内容と保存期間
ユーザーのクリップボード 抽出した商品情報（TSV形式: JANコード／仕入れ値（税込）／商品リンク）。以降の取り扱いはユーザーの管理下にあります。
ブラウザ内のローカル保存領域
（chrome.storage.local）		 直近1回の抽出結果: 処理状態（実行中／完了）、抽出対象ページのURL、抽出開始時刻、抽出完了時刻、抽出したTSV（JANコード・仕入れ値（税込）・商品リンク）、結果メッセージ、サイト名、抽出件数（以上8項目）。
保持するのは最新の1件のみで、履歴は残しません（次回の抽出結果で上書きされます）。
抽出から30分を過ぎた結果は再表示・復元に使用せず、ローカル保存領域から削除します。
ブラウザ内のローカル保存領域
（chrome.storage.local）		 パスワード認証の状態: 認証済みかどうかのフラグ、参照した設定ファイルのバージョン番号、入力失敗回数、入力ロック解除時刻、最終認証時刻。
入力されたパスワードそのものは保存しません。認証状態が更新されるまで保持されます。
ブラウザのメモリ（一時的） 抽出処理中の中間データ（取得した詳細ページの内容を含む）。処理の終了後、およびページを離れた時点で消去されます。
保存についての補足

chrome.storage.local はブラウザ内のローカル保存領域です。外部サーバーへの送信は行わず、Chromeアカウントを通じた同期も行いません（同期対象となる chrome.storage.sync は使用していません）。

保存期間（30分）を過ぎた抽出結果は、以下のいずれかの時点でローカル保存領域から実際に削除します。

  • 本拡張機能のポップアップを開いたとき
  • 保存された結果を読み出したとき（ポップアップでの再表示処理）
  • ブラウザを起動したとき、および本拡張機能が更新・インストールされたとき

いずれも本拡張機能が動作した時点で実行されるため、保存期間の経過後に本拡張機能を一度も起動しなかった場合は、次回の起動時まで削除は行われません。その間も、期限を過ぎた結果が画面に表示されることはありません。なお、次回の抽出を実行した時点で保存内容は新しい結果に上書きされます。

本拡張機能をアンインストールすると、上記のローカル保存領域の内容（抽出結果・認証状態）はすべて削除されます。

5. 商品詳細ページの自動取得について

バージョン 3.1.0 では、商品一覧ページにJANコードが表示されていない商品について、その商品の詳細ページを自動的に取得し、JANコードを読み取る機能を追加しました。この処理はユーザーが「抽出開始」を押したときのみ実行されます。

取得先の範囲

  • 取得先は、ユーザーが開いている商品一覧ページと同一サイト（同一オリジン）のページに限定されます。別サイトのURLは取得せずスキップし、スキップした件数を画面に表示します。
  • 例外として、Yahoo!ショッピングは商品一覧が shopping.yahoo.co.jp、商品詳細が store.shopping.yahoo.co.jp と別のサブドメインで提供されているため、この詳細ページのみ拡張機能のバックグラウンドから取得します（host_permissions に宣言済み）。
  • このバックグラウンドからの取得は、送信前に取得先URLを検証し、ホスト名が store.shopping.yahoo.co.jp と完全に一致し、かつ https であるものだけを実行します。それ以外のURLは、リクエストを送信せずに取得を中止します（商品一覧ページに広告・レコメンド由来の別サイトのURLが含まれていても、そのURLへは通信しません）。
  • 上記以外のサイトへ通信することはありません。

取得件数と負荷への配慮

  • 詳細ページの取得は5件ずつ、間に0.5秒の待機を入れて実行し、対象サイトへ連続的な負荷をかけないようにしています。
  • 1回の抽出につき最大150ページ、かつ最長120秒で処理を打ち切ります。また、1件あたりの取得は8秒応答がなければ中断します。これらの上限は、ページのレイアウトを自動判定する汎用モードと、サイト個別の抽出処理を用意しているサイトの両方に適用されます。打ち切った場合は未取得の件数と対処方法を画面に表示します。
  • サイト個別の抽出処理を用意しているサイトの場合も、取得対象は「いま開いている商品一覧ページに表示されている商品のうち、一覧上でJANコードが取得できなかったもの」に限られます。一覧に表示されていない商品や、他のページを巡回することはありません。

取得した内容の扱い

取得した詳細ページの内容は、JANコードの読み取りにのみ使用します。外部への送信も、ブラウザ内への保存も行わず、処理の終了後にメモリから破棄されます（保存されるのは読み取った結果のJANコードのみで、その扱いは「4. 情報の保存場所と保存期間」のとおりです）。

ご注意
詳細ページの取得は、ユーザーが同じページをブラウザで開いた場合と同等のアクセスとして行われます。ログイン情報等が別の宛先へ送られることはありません。

6. 外部への通信

本拡張機能が外部へ行う通信は、以下の2種類のみです。

通信先目的と送信内容
ユーザーが開いているECサイト
（およびその商品詳細ページ）		 商品情報およびJANコードの読み取りのためのページ取得（GET）です。ユーザー自身がそのサイトを閲覧するのと同じアクセスであり、抽出したデータをこのサイトへ送信することはありません。詳細は「5. 商品詳細ページの自動取得について」をご覧ください。
https://masa-labs.github.io/EC-/auth.json 本拡張機能の利用可否を判定するための設定ファイルの取得（GET）のみです。クエリパラメータもリクエスト本文も付けておらず、ユーザーの情報や抽出した商品データをこのURLへ送信することはありません。

パスワード認証の方式

本拡張機能はスクール受講生向けに限定公開されており、利用開始時にパスワードの入力を求めます。入力されたパスワードはブラウザ内で上記設定ファイル内のハッシュ値と照合され、パスワード自体が外部へ送信されることはありません。

連携していない外部サービス

本拡張機能は、以下の外部サービスとは連携していません:

  • Google Analytics等のアクセス解析サービス
  • 広告配信サービス
  • クラウドストレージサービス
  • 抽出データを収集・保管する提供者独自のサーバー・API

ユーザーの利用状況・閲覧履歴を収集して外部に送信することはありません。

通信に関する一般的な注意
一般的なHTTP通信の性質として、接続先のサーバー（ECサイト、および設定ファイルを配信するGitHub Pages）側に、接続元のIPアドレスやブラウザの種類が通常のアクセス記録として記録される場合があります。これは各サーバー運営者による記録であり、本拡張機能がそれ以上の情報を付加して送信することはありません。

7. 第三者への提供

本拡張機能は、ユーザーの情報を第三者に提供・売却することはありません。

取得したデータを、承認された用途（本ポリシー「3. 情報の利用目的」に記載した目的）以外で使用または転送することはありません。また、取得したデータをユーザーの認証情報として使用することもありません。

8. 使用する権限とその目的

本拡張機能は、Chromeブラウザに対して以下の権限を要求します。それぞれの利用目的は次のとおりです:

権限名利用目的
activeTab ユーザーが拡張機能アイコンをクリックして「抽出開始」を押した際に、そのタブのページから商品情報を抽出するために使用します。ユーザーが明示的に起動したタブ以外のページにはアクセスしません。
scripting 抽出対象のページに商品情報抽出スクリプトを動的に挿入するために使用します。挿入はユーザーが抽出ボタンを押した時のみ行われ、常時実行されるコンテンツスクリプトは登録していません。
clipboardWrite 抽出した商品情報をTSV形式でユーザーのクリップボードにコピーするために使用します。
storage 直近の抽出結果を chrome.storage.local に一時保存し、ポップアップを閉じて開き直したときに結果を再確認・再コピーできるようにするために使用します。あわせて、パスワード認証の状態（認証済みフラグ等）の保持にも使用します。保存内容と保存期間は「4. 情報の保存場所と保存期間」のとおりで、外部サーバーへの送信・Chromeアカウント同期は行いません。
tabs 抽出処理を行う対象タブを特定し、そのURLがHTTP/HTTPSのページであることを確認するため、および抽出処理の実行と結果の受け取りのために使用します。タブの閲覧履歴を取得・保存・送信することはありません。
host_permissions コンテンツスクリプトの挿入は上記 activeTab と scripting で行うため、host_permissions はそれ以外の以下の2件のみを宣言しています。
  • https://store.shopping.yahoo.co.jp/*: Yahoo!ショッピングの商品詳細ページを拡張機能のバックグラウンドから取得し、JANコードを読み取るため。
  • https://masa-labs.github.io/EC-/*: 利用可否を判定する設定ファイル（auth.json）を取得するため。取得するのはこのパス配下の当該ファイルのみです。
サイト個別の抽出処理を用意しているサイト（Joshin web ショップ・コジマネット・ちいかわマーケット等）については、ユーザーが「抽出開始」を押したタブのページ内容を読み取るだけで処理が完結するため、ホスト権限は宣言していません。上記2件のサイトにおいても、ページの読み取りが行われるのはユーザーが「抽出開始」を押したときのみです。
動作するページについて
本拡張機能はページのレイアウトを自動判定する汎用モードを備えているため、上記に列挙したサイト以外の幅広いECサイトでも動作します。ホスト権限を宣言していないサイトで動作するのはこの仕組みによるものであり、動作するのはユーザーが拡張機能アイコンをクリックして「抽出開始」を押したタブのみです。バックグラウンドで閲覧内容を監視することはありません。

9. ユーザーの権利

本拡張機能は個人情報を収集しないため、個人情報の開示・削除請求等の手続きは不要です。

ブラウザ内に保存された抽出結果は、保存から30分を過ぎた時点で削除対象となります（削除の実行タイミングは「4. 情報の保存場所と保存期間」のとおりです）。

抽出結果および認証状態は、Chromeの拡張機能管理画面（chrome://extensions/）から本拡張機能をアンインストールすることでも削除されます。アンインストールにより、すべての処理も停止します。

10. 本ポリシーの変更

本ポリシーは、法令の改正や本拡張機能の機能追加等に応じて、予告なく変更される場合があります。

変更後のポリシーは、本ページに掲載した時点から効力を生じるものとします。
